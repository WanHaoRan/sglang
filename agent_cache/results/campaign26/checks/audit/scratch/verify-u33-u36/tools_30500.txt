# Eviction replay for rule 3 (2026-11-11)

Which eviction score keeps the histories that return, on a recorded run's own timeline. CPU only.
Script `evict_replay.py`; outputs `evict_replay.out` (campaign 23's `jit_p50_c44`) and `evict_replay_a05.out`
(campaign 25's `jit_p50_a05`).

## The model

- One pool of M tokens holds session histories. A running turn's session is locked.
- A returning turn whose history is not all in memory reads the rest from SSD; it counts as a read turn when 256
  tokens or more are missing.
- Over M, idle histories are evicted from their tails, lowest priority first.
- Each policy sees what the engine sees: the entry sent with the finished turn (p10, p50, p90), the idle time and the
  explicit end signal. Only the exact row sees the true gap.
- M is set once so that LRU reads on 19.4 % of returning turns, the hint-free arm's measured share (982K tokens).

The timeline is the run's own, so this ranks eviction orders; it does not predict TTFT. Read pins, the GPU and host
split and partial reads are not modelled.

def end_labels(ax, x, ends, gap=11.0):
    """A dot at each line end and its label beside it, in ink; labels closer than gap points are spread, keeping their order."""
    to_pt = 72.0 / ax.figure.dpi
    ends = sorted(ends, key=lambda e: e[1])
    true = [ax.transData.transform((x, y))[1] * to_pt for _, y in ends]
    lo, hi = (v * to_pt for v in ax.get_window_extent().intervaly)
    at = list(true)
    for _ in range(200):  # neighbours too close move apart by the same amount, so a cluster stays centred on its dots
        short = [(i, gap - (at[i + 1] - at[i])) for i in range(len(at) - 1) if at[i + 1] - at[i] < gap - 0.01]
        if not short:
