What the agent sends

A table with each request: for each kind of tool call (the tool and the command’s first word), the p10, p50 and p90 of past gaps, and whether the session is over.

What the engine reads off it

Φ: that row’s gap distribution. After a seconds idle, F(x | a) = [Φ(a + x) − Φ(a)] / [1 − Φ(a)] is the chance of return within x more seconds, and h(a) the same chance per second, right now.

Two shapes

Sharp: h rises with a, so waiting narrows down the return. Heavy-tailed: h falls, so the longer idle, the less likely back soon. Here h falls beyond 2 s for 94 % of requests.

Φ: distribution of the gap G · a: seconds idle so far · F(x | a): chance the gap ends within x more seconds · h(a): return rate (hazard). FreeInference sessions as replayed, 103K gaps.

The agent’s forecast of the gap is the hint. It is not a number. With each request the agent framework sends a small table: for each kind of tool call, meaning the tool and the first word of its command, the tenth, fiftieth and ninetieth percentile of the gaps it has seen after such calls, and a flag for a session that is over. When the engine finishes a reply, it reads the tool call from its own output and picks the row. The table on this slide shows four rows from the workload. A cd in a shell is the most common call: half of the gaps after it end within 1.1 seconds, a tenth last over 5.6. After a reply with no tool call a person has to answer: the median is 68 seconds, a tenth last over twelve minutes, and 22 percent of those sessions never return. The engine turns a row into a distribution, phi, and from it two functions of the time a the session has already been idle: F of x given a, the chance of return within x more seconds, and h of a, the return rate, which is the same chance per second right now. The shape of the row matters more than its median. In a sharp row, like a web search or a sleep, the rate rises: the longer the session has been idle, the sooner it will be back. In a heavy-tailed row the rate falls: most sessions return at once, and one that has not is less and less likely to return soon. On this trace the rate falls beyond two seconds for the rows of 94 percent of requests. The design uses the two shapes differently.
