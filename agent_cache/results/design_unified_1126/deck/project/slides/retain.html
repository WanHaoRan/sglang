The four actions · Retain, part 1

Retain: keep a copy while its index is above the price

ν(a) = (K / L) · max over h of F(h | a) / τ(h | a)

Keep while ν(a) > λ. Drop at the first idle age where it is not.

K: what it costs if the copy is gone when the session returns · L: its tokens · F(h | a): chance of return within h more seconds · τ(h | a): expected seconds the copy is held if kept h more, E[min(time to return, h)] · λ: price of a host token-second

Why

Keeping for h more seconds costs rent λ · L · τ and saves K with chance F. Some h pays exactly when ν > λ. A session that has been kept faces the same test again, so the first age that fails it is the best moment to drop.

Exact hint, back in R₀ seconds

ν = K / (L · R₀): evict the farthest next use. Belady’s rule.

Return rate falling

ν = (K / L) · h(a): with one law for all, evict the longest idle. LRU.

Session over

ν = 0: first out, and nothing of it is worth writing.

Two modes, 1 s or 40 s

Keep through the gap between them: looking only at the rate now would drop it and cost 1.8 times more.

ν is the Gittins index of a job of unknown size (the gap), and the slope of the lower convex hull of the curve (expected seconds held, chance still away). Checked exactly on 12 gap laws and 37 prices.

Retain decides which copies a tier keeps. Take one idle session whose prefix of L tokens sits in host memory. Keeping it costs rent: lambda, the price of a host token-second, times L, for every second it stays. Dropping it costs K if the session returns and the copy is gone: K is the restore cost, a read or a recompute. The session has been idle for a seconds, and the only news over time is that it is not back yet. Suppose we keep the copy for h more seconds. The rent is lambda L times tau, the expected seconds it is actually held, and with chance F, the chance of return within h, we save K. So some horizon pays exactly when K times F exceeds lambda L tau for some h, which is the statement that the index nu, K over L times the best ratio of F to tau, exceeds lambda. And a session that was kept faces the very same test later, so the best policy is simple: keep while the index is above the price, and drop at the first age where it is not. This index is the Gittins index of a job of unknown size, where the job is the gap. It contains the classical policies. With an exact hint, the index is K over L times the time to return: evict the farthest next use, which is Belady’s rule. With a falling return rate the best horizon is zero and the index is the rate itself: with one law for all sessions, evict the one idle the longest, which is LRU. For a session that is over the index is zero. And for a gap with two modes, say one second or forty, the index looks ahead across the dead stretch, where a rule that only looks at the current rate would drop the copy at once and pay 1.8 times more.
