KV cache tiering for agent sessions · the unified design

Four actions, three prices

One set of rules for when to read, what to keep and when to write across GPU memory, host memory and SSD, with the queue and the tool call’s duration in the model, and what can be proved about it

26 November 2026

This deck presents the unified design for moving an agent session’s prefix cache between GPU memory, host memory and SSD. It keeps the four actions of the paper draft, Fetch, Preempt, Retain and Price, and extends them so that the same four actions decide when a read starts and in what order reads are served, what each tier keeps, and when and in what order pages are written to the SSD. Two things enter the model that the earlier design took as given: the wait in the GPU queue, and the hint, which is a distribution of how long the agent’s tool call will run. The deck needs no earlier context. It defines every symbol where it first appears, derives each rule from one cost statement, says what is proved and under which assumptions, and then reports the checks: on logs of earlier runs, in a calibrated simulator, and on the GPU against the current design.
