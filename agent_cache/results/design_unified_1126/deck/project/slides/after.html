The four actions · Fetch, part 1

Fetch: land the read at a quantile of admission

The turn is here; its read will land at ℓ; the GPU would take it at D, known only roughly.

cost(ℓ) = c · E[(ℓ − D)⁺] + λL · E[(D − ℓ)⁺]

Late: the turn stalls, at weight c. Early: L tokens sit pinned in host memory until admission, at price λ.

P(D ≤ ℓ*) = q, q = λL / (c + λL)

The derivative of the cost in ℓ is (c + λL) · (P(D ≤ ℓ) − q): negative before the q-quantile of D, positive after. Release the read one read time before ℓ*.

How it moves

Memory cheap and stalls dear, q near 0: land early. Memory dear and stalls cheap, q near 1: land at the last moment.

What the engine does

It starts a queued turn’s read a fixed 2 s early: measured, the 20th percentile of its estimate’s error, within 1 to 4 % of the best cost.

A guard

At saturation c and λ both go to 0 and q is noise: it is held between 0.05 and 0.5.

ℓ: when the read lands · D = A + W: when the GPU would take the turn · L: tokens the read brings in · c: weight of a second of stall · λ: price of a host token-second · (z)⁺ = max(z, 0)

Fetch decides when a copy moves up. Start with the common case: the turn has arrived and is waiting in the queue, and its history has to be read from the SSD. The read will land at some time l. The GPU would take the turn at D, which the engine knows only roughly, from the queue ahead. If the read lands late, the turn stalls, at weight c per second. If it lands early, L tokens sit pinned in host memory until admission, at the price lambda per token-second. This is the newsvendor problem, and its answer is a quantile: land the read where the chance that the GPU is already waiting equals q, with q equal to lambda L over c plus lambda L. The derivation is one line: the derivative of the cost in the landing time is c plus lambda L, times the chance that D is at most l minus q, so the cost falls before the q-quantile and rises after it. The read is released one read time before that point. The rule moves the right way. If memory is cheap and stalls are dear, q is near zero: land early and never make the turn wait. If memory is dear and stalls are cheap, q is near one: land at the last moment and hold nothing. The engine today starts a queued turn’s read a fixed two seconds early. Measured against the error of its own estimate of D, two seconds is the twentieth percentile, and within one to four percent of the best cost, so the constant was a good one; the rule says why, and how it should move with the prices. One guard is needed: at saturation c and lambda both go to zero and their ratio is noise, so q is held between 0.05 and 0.5.
